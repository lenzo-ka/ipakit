Core inputs: pkg/transcriptionsystems/bipa and shared feature/metadata files.
Exact inputs, content hashes, references and attribution are in source.json
and repeated in the generated snapshot's source record.

Changes: exact sound feature sets and canonical spellings were extracted with
pyclts 4.0.2. Lookup keys retain core dictionary spellings and literal declared
source aliases where actual resolution proves the same core sound. Unicode
normalization and alias changes are recorded. Markers and unresolved literal
source fields are reported but not scored. Unused fields, aggregated source
datasets, productive resolution and phonetic mappings are not included.
Keys and set labels are sorted and encoded in IPAkit's versioned JSON format.
No endorsement by the original creators is implied.

pyclts is a separate optional development dependency, Apache-2.0 licensed:
https://github.com/cldf-clts/pyclts
No pyclts implementation is copied into the snapshot or IPAkit runtime.
